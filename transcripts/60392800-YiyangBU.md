## Stage 1 — Requirements classification

### Turn 1.1 — Topic and safety boundary
- **Agent proposal**: Suggested a from-scratch personal-expense tool in which an LLM suggests a
  budget category, with deterministic code enforcing the whitelist, amount conservation, and
  budget compliance. Confirmed no prior-group code, naming, or docs would be reused.
- **Human action [APPROVED with scope redirection]**: Approved the topic, but redirected the
  boundary to be explicit and testable: the model may only produce a candidate; a guardrail and
  budget policy must own acceptance and compliance. Reason: the course requires a genuine AI
  component **and** an enforceable safety-relevant boundary; a vague "AI reviews the result"
  would not satisfy INV-001…006.
- **Result**: Scope locked in blueprint §1; advisory vs authority split fixed in blueprint §5.

### Turn 1.2 — Requirement extraction and typing
- **Agent proposal**: Drafted requirement entries grouped by functional, invariant, quality,
  performance, cost, governance, security, each with a fit criterion and MoSCoW priority.
- **Human action [QUESTIONED]**: Challenged every fit criterion to be machine-checkable
  (metric + threshold + verification), rejected any vague threshold such as "fast enough" or
  "good accuracy". Invariants were marked zero-tolerance with a failing-test counterpart.
- **Result**: 25 requirements in `docs/req/requirements.yaml`; schema in `req-schema.json`.
- **Human note**: The human fixed requirement IDs, whitelist categories, and thresholds; the
  agent did not introduce extra requirements (recorded in `docs/ai-use-log.yaml` AU-002).

### Turn 1.3 — Registry parse failure (BUG-001)

- **Result**: BUG-001 recorded; schema gate runs a YAML load before schema validation.

### Turn 1.4 — Registry type mismatch (BUG-002)

- **Human action [REDIRECTED]**: Identified that `group: 43` was coerced to integer against a

- **Result**: BUG-002 recorded; schema gate enforces type/pattern.

### Turn 2.1 — Candidate architectures
- **Agent proposal**: Generated four candidates — (A) guarded hybrid, (B) model-direct write to
  ledger, (C) rules-only, (D) retrieval-augmented over a local corpus, plus (E) separate model

### Turn 2.3 — Authority boundary and frozen paths
